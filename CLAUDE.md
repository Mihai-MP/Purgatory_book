# «Чистилище» — книга. Нотатки для Claude

- Мова тексту й нотаток — українська. Це книга, не код: тут немає збірок і тестів.
- Почни сесію з `notes.md` (коротко: стан, рішення автора, наступні кроки, відкриті питання). Решту читай частинами, лише потрібне (`grep -n`), а не цілими файлами: розділи книги великі.
- **Лор** — `lore/` (`world.md`, `characters.md`, `plot.md` — хронологія й таблиця актів, `act1.md` — скелет Акту 1). Це джерело правди і для книги, і для гри (гра — репозиторій `Mihai-MP/chystylyshche`; згадки «у грі», шляхи на кшталт `prototypes/…` чи `data/…` стосуються її). Не суперечи лору; незатверджене позначай **[ідея]**. Нові рішення автора записуй у лор одразу.
- **Книга** — `book/actN/` по розділу на файл (`00_prolog.md`, `01_….md`…), плюс `short.md`: скорочений переказ акту і список вигаданого, що чекає на затвердження.
- **Стиль** (рішення автора): третя особа; темно, по-дорослому, без пом'якшень (кров, смерть, жорстокість — прямо); інтимне — натяком. Твій перший текст автора («Пролог», «Той день», «Клітинні поля») — у `sources/original_prolog_toi_den_klitynni_polia.docx`; при переписуванні зберігати події й ключові репліки.
- **Арти автора** (прототипи фан-артів, на них можна спиратися щодо вигляду) — `sources/art/`.
- Робочий процес: автор називає ключові точки — ти заповнюєш проміжки й питаєш (питання з варіантами, по черзі). Перед великим текстом — спитати, потім писати без зупинок.
- Коли закінчуєш: у `notes.md` — рядок у «Стан», нові кроки й питання (тримай його коротким).
